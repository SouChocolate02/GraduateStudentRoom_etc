## その他雑多なもの

- ESLint
- One Dark Pro
- Image preview：
    ポインタを当てるとイメージが表示される
    行番号の横にサムネが表示される
- Material Icon Theme：
    各種ファイルにアイコンを表示
- indent-rainbow：
    インデントに色を付ける
- Error Lens：
    エラー部分に色を付けて表示
- Live Preview
    HTMLファイルをリロードせずにVSCode内部で表示確認ができる
- GitLens：
    各行のコードがいつ・誰が書いたのかがわかる
- Prettier：
    コードを自動的にきれいに成型する
- Live Sever：
    Web開発の自動更新機能-コードを変更すると自動的にブラウザが更新される
- ESLint：
    エラーや悪い書き方を教えてくれる
- Auto Rename Tag：
    HTMLタグの名前を変更すると終了タグを自動的に編集する
- Bracket Pair Colorzier：
    カッコに異なる色を付け，どのカッコを編集しているかわかりやすくする
- EchoAPI：
    VSCodeを離れずにAPIをテストできる
- GitHub Copilot：
    コメントや部分的なコードを書くと補完してくる
- Import Cost：
    インポートする各コードパッケージのサイズを表示する
- CSS Peek
    htmlでクラス・ID名をポイントすると対応するCSSコードを教えてくれる
- HTML Hint
    htmlのミスを指摘する
