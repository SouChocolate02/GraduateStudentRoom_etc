\section{方程式}%\index{方程式@ほうていしき}
\subsection{(一次/二次)方程式}%\index{一次方程式@一次方程式}%\index{二次方程式@にじほうていしき}
    中学で習ったような一次または二次方程式を考える\footnote{化学でそれ以上高次の方程式を解く機会はない？ような気がする}。
    \S\ref{sec:四則演算}で学んだように例えば一次方程式\eqref{eq:一次方程式}、二次方程式\eqref{eq:二次方程式}
\begin{equation}\label{eq:一次方程式}
    ax+ b= 0\ \ (a\ne 0)
\end{equation}
\begin{equation}\label{eq:二次方程式}
    ax^2+ bx+ c= 0\ \ (a\ne 0)
\end{equation}
    を(頑張って腕力で)式変形して一次方程式の解の公式\eqref{eq:一次方程式の解の公式}、二次方程式の解の公式\eqref{eq:二次方程式の解の公式}
\begin{equation}\label{eq:一次方程式の解の公式}
    x= -\frac{b}{a}
\end{equation}
\begin{equation}\label{eq:二次方程式の解の公式}
    x= \frac{-b\pm \sqrt{b^2- 4ac}}{2a}
\end{equation}
    としてもよいが、毎回この形に変形する手間をかけるのは現実的ではない\footnote{係数が煩雑になったときに面倒だし、そもそもこれを入力するのが面倒}。

\begin{tcolorbox}
    価数1の弱酸遊離反応\ce{HA <=> H+ + A-}(初期濃度C[mol/L]、電離定数$\mathrm{K_a}$)の平衡状態について考える。ただし水の電離は無視する。




    % 以下の二次方程式\eqref{eq:例題・二次方程式}を$x$について解け。
    初期濃度C= \SI{1.0}{\mole/L}
    \begin{equation}\label{eq:例題・二次方程式}
    2x^2- 1= 0
\end{equation}
\end{tcolorbox}

\begin{lstlisting}[caption= {Pythonで二次方程式を解く}, label={code:Pythonで二次方程式を解く}]
    import sympy as sp
    x= sp.symbol('x')
    sp.solve(2*x- 1, x)
\end{lstlisting}
    なおこの\cref{code:Pythonで二次方程式を解く}は以下の\cref{code:Pythonで二次方程式を解く・改良型}のように書き換えることもできる。
\begin{lstlisting}[caption= {Pythonで二次方程式を解く・改良型}, label= {code:Pythonで二次方程式を解く・改良型}]
    import sympy as sp
    x= sp.symbol('x')
    f= 2*x**2- 1
    sp.solve(f, x)
\end{lstlisting}
    \cref{code:Pythonで二次方程式を解く・改良型}では解く対象となる方程式を$f:=2x^2- 1$と定義しているため拡張性が高い。
    つまり解くべき方程式が変化しても\cref{code:Pythonで二次方程式を解く}であれば\type{3}行目(実際に方程式を解いているところ)の式を丸々書き換えなければいけなかったが、\cref{code:Pythonで二次方程式を解く・改良型}であれば\type{3}行目(解くべき式を定義しているところ)を書き換えるだけでよい。
    一次方程式も同様に解くべき式を定義する部分を書き換えるだけで同様に解くことができるのでここでは例を挙げた省略する。
    他方程式についても同様に解くことができるが、Pythonでの記法の練習も兼ねて具体的に方程式を例示し、解くコードを与える。

\subsection{微分方程式}%\index{微分方程式@びぶんほうていしき}
    ここでは\type{Numpy}の機能を使って微分方程式を解くことを考える。微分方程式とは通常の方程式とは異なり、解として方程式が得られる。
\begin{table}[h]
\caption{方程式と微分方程式の違い}
\begin{center}
\begin{tabular}{lcl}\hline\hline
    種類& 方程式の形状&得られるモノ\\ \hline
    方程式& & 数値($x= 1.0,\ y= 6.5$など)\\
    微分方程式& $\frac{dx}{dt}= C,\ \frac{dy^2}{dx^2}= -y$& 方程式($x= Ce^t$や$y= C_1\sin{x}+ C_2\cos{x}$など)\\ \hline\hline
\end{tabular}
\end{center}
\end{table}
    基本的に微分方程式は解くことができない\footnote{化学で扱う程度であれば解ける　か解けることにする}が、本節では解ける微分方程式のみを扱う。
\begin{tcolorbox}
    反応係数を$k$として反応物\ce{A}が\ce{B}に変化する不可逆な一次反応\ce{A ->[$k$] B}を考える。
    以下の微分方程式(一次反応の微分方程式)を解け。
\begin{equation}\label{eq:微分方程式}
    \frac{d[A]}{dt}= -k[A]
\end{equation}
\end{tcolorbox}

\begin{lstlisting}[caption= {Pythonで微分方程式を解く}, label= {Pythonで微分方程式を解く}]
    import from sympy *
    x= symbol(x)
    f= 
    dsolve[f, x]
\end{lstlisting}
    他の方程式を解く際は最後が\type{solve}だったが、微分方程式のときには\type{\underline{d}solve}であることに注意する。
